# Guia do Sistema

Página de orientação integrada em `/guia`, acessível após login. O menu principal e o menu móvel exibem o acesso.

## Funcionalidades
- 14 tópicos de orientação;
- pesquisa de assuntos, índice lateral e adaptação para celular;
- links para abrir diretamente as telas do projeto (respeitando permissões existentes);
- explicação dos limites entre a demonstração web e a integração de sensores que exige validação.

**Pré-visualizações:** as 13 imagens exibidas no guia são ilustrações esquemáticas das respectivas telas, não screenshots. O pacote original de capturas, tratado fora do repositório, pode ser integrado mais tarde com revisão de privacidade, já que algumas telas exibem nomes, e-mails e outros dados. As informações operacionais apresentadas no guia não substituem inspeção nem protocolos de segurança.
